## Why is This Prediction Reasonable?

Detailed mechanism of action data is not available in the data compiled for this report. Based on known pharmacology, dihydrotachysterol is a vitamin D analogue. It is hydroxylated in the liver to 25-hydroxydihydrotachysterol, which acts on the vitamin D receptor without needing the renal 1-alpha-hydroxylation step.

Because it acts on the same pathway that vitamin D deficiency disrupts, treating that deficiency is mechanistically plausible. It also overlaps with other calcium and bone-mineral disorders for which vitamin D analogues are used.

Two cautions apply. First, the disease term is flagged as obsolete, so the exact clinical entity being predicted is unclear. Second, the high score is a model output and is not clinical evidence. The data compiled for this report contain no trials or publications for this prediction, so the evidence level is L5.

## Safety Considerations

**Drug Interactions** (50 interactions recorded; main examples):
- **Major:** cholecalciferol, calcifediol, calcitriol, doxercalciferol and burosumab. Combining vitamin D products raises the risk of hypercalcaemia, and burosumab is a particular concern.
- **Moderate:** thiazide and thiazide-like diuretics (hydrochlorothiazide, chlorothiazide, chlorthalidone), digoxin, enzyme-inducing drugs (carbamazepine, amobarbital, butalbital, rifabutin), bile acid sequestrants (cholestyramine, colesevelam, colestipol), sevelamer, magnesium oxide, and topical calcipotriol and calcitriol.
